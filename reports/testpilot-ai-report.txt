  TestPilot AI - Intelligent Test Generation Framework
======================================================================

Author: Maharshi Soni
Category: qa-ai-automation
Difficulty: advanced

----------------------------------------------------------------------
DESCRIPTION
----------------------------------------------------------------------
A pip-installable test generation framework using AST parsing. Generates comprehensive pytest suites with boundary value analysis, equivalence partitioning, and LLM-enhanced generation.

----------------------------------------------------------------------
TECH STACK
----------------------------------------------------------------------
  - click
  - pydantic
  - pytest
  - jinja2

----------------------------------------------------------------------
FEATURES
----------------------------------------------------------------------
  * AST-based code analysis
  * Boundary value test generation
  * Equivalence partitioning
  * LLM-enhanced generation (Claude CLI default)
  * pytest plugin
  * Coverage gap detection

----------------------------------------------------------------------
SAMPLE INPUT
----------------------------------------------------------------------
  Python source files

  Example:
    testpilot generate --source src/ --output tests/

----------------------------------------------------------------------
SAMPLE OUTPUT
----------------------------------------------------------------------
  Generated pytest test files

  Example:
    testpilot analyze --source calculator.py
